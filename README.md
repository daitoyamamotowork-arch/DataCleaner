# DataCleaner

CSV / Excel データをブラウザ上で確認し、**重複・空欄・URL・電話番号表記などを簡単に整理できるWebアプリ**です。

Python と Streamlit を使用して作成しており、データ整理や事務作業の効率化を想定しています。

## 🌐 デモ

インストール不要で、ブラウザからDataCleanerを試すことができます。

👉 **[DataCleanerを試す](https://datacleaner-daito.streamlit.app/)**

CSV または Excel ファイルをアップロードすると、重複・空欄・URL・電話番号表記などの整理結果を確認できます。

## ツール概要

DataCleaner は、CSV / Excel ファイルをアップロードすると、選択した処理を自動で実行し、整理前後のデータを比較できるツールです。

処理後のデータは新しい Excel ファイルとしてダウンロードできるため、元ファイルを上書きせずに利用できます。

## 主な機能

* CSV / Excel（`.xlsx`）ファイルのアップロード
* 処理前・処理後データのプレビュー
* 文字列の前後にある不要な空白の削除
* 完全一致する重複行の検出・削除
* 空欄セルの検出
* URL形式のチェック
* 電話番号の全角数字を半角数字へ変換
* 電話番号のハイフン表記を統一
* 問題があるデータを「要確認データ」として一覧表示
* 整理結果の件数表示
* 整理後データの Excel ダウンロード

## 動作確認

実際に複数のテストデータを使用し、以下のケースで動作確認を行いました。

* 通常の Excel データ
* 完全一致する重複行を含むデータ
* 空欄セルを含むデータ
* 不正な形式の URL を含むデータ
* 全角数字や異なるハイフン表記を含む電話番号
* 文字列の前後に空白が含まれるデータ
* 想定していた列名とは異なる Excel データ
* データがほとんど入っていない Excel ファイル

想定外の列構成でもアプリが停止せず、利用可能な処理のみを実行できることを確認しています。

## 工夫した点

### 1. 元データを勝手に変更しない設計

不正な URL や空欄など、機械的に正しい値を判断できない項目については、自動修正を行わず「要確認データ」として表示するようにしました。

これにより、誤った値への自動変換を防ぎながら、確認が必要な箇所を効率よく見つけられます。

### 2. 処理前後を簡単に比較できるUI

「処理前データ」「処理後データ」「要確認データ」をタブで切り替えられるようにし、どのようにデータが変更されたか確認しやすくしました。

### 3. 初めて使う人でも操作しやすい画面構成

画面を以下の4ステップに分けています。

1. ファイルをアップロード
2. 整理する内容を選択
3. 整理結果を確認
4. 整理後データを保存

専門的な操作を覚えなくても、画面の流れに沿って利用できる構成を意識しました。

### 4. データ形式への依存を抑えた設計

会社情報だけでなく、商品データなど異なる列構成の Excel ファイルでも処理できるようにしています。

URLや電話番号については列名から候補を自動選択し、必要に応じてユーザーが対象列を変更できます。

# 初めて使う方へ（Windows）

パソコン操作に慣れていない方は、**基本的にコマンド入力は不要**です。

最初の1回だけ `setup.bat` を実行し、2回目以降は `run.bat` をダブルクリックするだけで起動できます。

## 1. Python をインストールする

DataCleaner を動かすには Python 3.10 以上が必要です。

1. Python の公式サイトから Windows 用 Python をダウンロードします。
2. ダウンロードしたインストーラーを開きます。
3. インストール画面に **「Add python.exe to PATH」** という項目が表示された場合は、チェックを入れてください。
4. **Install Now** を選択してインストールします。
5. インストールが完了したら画面を閉じます。

Python をすでにインストールしている場合、この作業は不要です。

## 2. DataCleaner をダウンロードする

GitHub のこのリポジトリを開き、画面上部の **Code** ボタンから **Download ZIP** を選択します。

ダウンロード後は ZIP ファイルを右クリックして **「すべて展開」** を選び、通常のフォルダに展開してください。

> ZIP ファイルの中に入ったまま `setup.bat` や `run.bat` を実行せず、必ず先に「すべて展開」してください。

## 3. 初回セットアップを行う

展開した `DataCleaner` フォルダを開き、次のファイルを探します。

```text
setup.bat
```

`setup.bat` をダブルクリックしてください。

黒い画面が開き、DataCleaner に必要な環境とライブラリが自動的に準備されます。途中で処理に少し時間がかかる場合があります。

最後に次のようなメッセージが表示されればセットアップ完了です。

```text
Setup completed successfully.
Next time, double-click run.bat to start DataCleaner.
```

`setup.bat` は基本的に**最初の1回だけ**実行すれば大丈夫です。

### 「Python was not found」と表示された場合

Python がインストールされていないか、Windows が Python を見つけられていません。

上の「1. Python をインストールする」に戻り、Python をインストールしてから `setup.bat` をもう一度実行してください。

## 4. DataCleaner を起動する

セットアップが完了したら、同じフォルダ内にある

```text
run.bat
```

をダブルクリックします。

しばらくするとブラウザが自動的に開き、DataCleaner の画面が表示されます。

あとは画面の「CSVまたはExcelファイルを選択」からファイルをアップロードして利用できます。

## 5. 2回目以降の起動

2回目以降は `setup.bat` を実行する必要はありません。

**`run.bat` をダブルクリックするだけで起動できます。**

## 終了方法

DataCleaner を終了するときは、起動時に開いた黒い画面を閉じてください。

ブラウザのタブを閉じるだけでは、DataCleaner の処理がパソコン上で動き続けている場合があります。

## Windows の警告画面が表示された場合

Windows の設定によっては、`.bat` ファイルを実行すると警告が表示される場合があります。

このリポジトリから自分でダウンロードした `setup.bat` / `run.bat` であることを確認したうえで実行してください。不明な場所から入手したファイルは実行しないでください。

# 開発者向けセットアップ

コマンドラインから利用したい場合は、以下の方法でもセットアップできます。

## 仮想環境の作成

```bash
python -m venv .venv
```

## 仮想環境の有効化

Windows：

```bash
.venv\Scripts\activate
```

macOS / Linux：

```bash
source .venv/bin/activate
```

## 必要なライブラリのインストール

```bash
python -m pip install -r requirements.txt
```

## 起動

```bash
python -m streamlit run app.py
```

ブラウザで DataCleaner が起動したら、CSV または Excel ファイルをアップロードしてください。
